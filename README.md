# Maddie's Quest ❤️

A small original cozy pixel-art RPG built as a personal boyfriend proposal game.

## Run it

No build system is required.

1. Put `index.html`, `style.css`, and `game.js` in a GitHub repository.
2. Enable **GitHub Pages** in the repository settings.
3. Open the Pages URL.

You can also open `index.html` locally in a browser.

## Controls

- WASD / Arrow Keys — move
- E — interact
- Mouse/touch — buttons and menus

## Important customization points

Open `game.js` and edit:

- `journalEntries` for the real journal entries and poem.
- `openPhone()` for the exact text messages.
- `openLetter()` for the final letter.
- Character drawing functions for more accurate sprites.
- `drawStaffRoom()` for staff member placement.
- `drawOffice()` for the real whiteboard drawings.
- `drawPhaseRoom()` / `drawKimora()` for Kimora.
- `drawPoolRoom()` for the basement.
- `drawBirthdayRoom()` for the birthday scene.

The visual style is an original cozy pixel-art style rather than using Stardew Valley assets.
